# Osu Clicks

Un mod ligero para **Geometry Dash** (Geode) que reproduce el sonido de clic clásico de **osu!** cada vez que saltas o presionas para jugar.

## Características

- Reproduce el sonido de clic de **osu!** al presionar el botón de salto.
- Ligero, sin dependencias externas ni descargas en línea.
- Compatible con **Geometry Dash v2.2091** y **Geode v6.0.0** en Windows.

## Instalación

1. Descarga el archivo `.geode` desde la pestaña **Actions** (en *Artifacts -> Build Output*) o desde **Releases**.
2. Abre **Geometry Dash**, entra al menú de **Geode** y haz clic en el ícono de ajustes (**Settings**).
3. Selecciona **Install From File** y elige el archivo `.geode` descargado (o cópialo manualmente en `GeometryDash/geode/mods/`).
4. Reinicia el juego.

## Cómo cambiar el sonido

Si quieres usar otro sonido de clic en el futuro:
1. Reemplaza el archivo dentro de la carpeta `resources/` por tu propio audio (`.wav` o `.ogg`).

## Créditos

- Desarrollado con [Geode SDK](https://geode-sdk.org).
- Sonido de clic perteneciente a **osu!**.
